### 自我介绍

我是一名香港程序员,对软件,电子,嵌入式等领域都略有研究

软件方面,我熟悉c++,熟悉现代c++特性,对内存模型熟悉,略知从c++到汇编的编译过程细节,略知汇编

我在网络方面略有建树,熟悉各项通信协议,曾基于c++,httplib库与mysql c api开发”一个基于 http服务的环境参数监测系统”,在这一系统开发过程中运用了不少现代c++特性,如lambda表达式,迭代器,以及std::string,std::map等stl容器,同时,为实现多线程的mysql句柄管理,特手动实现了连接池,用于复用已建立的网络连接,避免重复建立连接带来的延迟问题及多线程间的原子性问题,这一系统现可用于[Endermy/sba](https://github.com/Endermy/sba)

中四期间建立了[木木的中转站](http://mumuserver.com) 并持续维护至今,这一网站前端基于html和css手写,未使用任何前端框架,这一网站包括:ftp服务,http文件传输,基于直接下载的日程表系统及基于docker的网站在线监测服务,该网站现已通过备案

我在控制论方面略有了解,正在学习四元数,矩阵等数学工具及机器人运动学
